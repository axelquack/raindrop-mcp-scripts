# Docs

Code repository. This page is the contributor index. The script guide, the setup steps, and the API notes stay in `README.md`. The changelog stays at `CHANGELOG.md`.

Do not run `raindrop_cleanup.py`, `raindrop_importer.py`, or any call to the Raindrop API. Those scripts change bookmarks. Offline checks are `python3 -m py_compile` on the three scripts, and `just lint`. Never open `.env`. Keep `.env.example`.
